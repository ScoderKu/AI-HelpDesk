# General Technical Reference Library

This directory contains reusable learning material that is retained for maintainers and future educational use. It is deliberately outside `knowledge/` and is not mounted or indexed by the AI HelpDesk RAG service.

Topics include programming-language foundations, development environments, operating-system troubleshooting and child-friendly Scratch instruction. These subjects are expected to be answered by the language model from its general training unless a future, evidence-based decision adds a narrowly scoped project-specific reference.

Do not move these guides back into the RAG corpus simply because they mention technologies used by AI HelpDesk. Extract only verified project-specific behavior into a dedicated `knowledge/` document.
